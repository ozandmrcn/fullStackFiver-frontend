# fiverrClient

Welcome to the **fiverrClient** project! A modern, highly responsive, and visually stunning frontend built with **React**, **TypeScript**, and **TailwindCSS**. This application provides a premium user experience for the Fiverr clone, featuring smooth animations and real-time data handling.

## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Activities/Bullseye.png" alt="Bullseye" width="25" height="25" /> Project Overview

fiverrClient provides an intuitive interface for users to:

- **Explore Gigs:** Browse and filter service listings with a high-performance UI.
- **Dynamic Content:** Real-time data fetching and synchronization using **React Query**.
- **Responsive Design:** A fully adaptive layout powered by **TailwindCSS**, ensuring a great experience on all devices.
- **Interactive Carousels:** Smooth image sliders and carousels implemented with **SplideJS**.
- **Secure Integration:** Seamless communication with the backend API via **Axios** with credential support.

- **Vite-Powered Speed:** Ultra-fast development and build times using **Vite**.

To run the frontend locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/ozandmrcn/fullStackFiverr.git

# Navigate to the client folder
cd fullStackFiverr/client

# Install required dependencies
npm install

# Start the development server
npm run dev

# Build the project for production
npm run build
```

### ⚙️ Environment Variables (.env Setup)

Create a `.env` file in the `client` directory and define the following variables:

```env
# API Configuration
VITE_API_URL=http://localhost:4000/api/
```

> ⚠️ **Note:** Ensure the backend API is running at the specified URL for the application to function correctly.
